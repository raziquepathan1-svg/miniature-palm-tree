Privacy Policy

Health Support Studio Uploader

Last updated: September 27, 2026

Health Support Studio Uploader is a private tool used only by the owner of the Health Support Studio YouTube channel (healthsupportstudio@gmail.com) to upload the channel's own educational videos.

What it accesses

Only the owner's own YouTube channel, through the YouTube Data API, to upload videos, set thumbnails and read the channel ID.

What it collects

It collects no data from any other person. It does not collect, store, sell or share personal information.

How credentials are kept

The owner's access credentials are stored as encrypted secrets and used only to upload the owner's videos. Access can be removed at any time at myaccount.google.com/permissions.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
