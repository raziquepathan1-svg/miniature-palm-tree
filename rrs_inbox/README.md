# Restore Remake Studio inbox

The **free AI clips (Kaggle)** workflow also puts its clips here by itself (one folder per makeover),
so uploading by hand is optional.

Upload the AI video clips of **one makeover** here (usually 3 clips: clean up → build → finish).

1. Open this folder on GitHub (phone browser is fine).
2. **Add file → Upload files**, pick all clips of the makeover together, then **Commit changes**.
3. A run starts by itself and, in about 5 minutes, makes the Short, schedules it on YouTube
   (with the AI-generated label) and readies it for Instagram and Facebook.
   The clips are then moved to `rrs_clips/` for the long compilation.

Tips
- One makeover per upload. Wait until this folder is empty again before uploading the next one.
- Clips from Google Flow are joined in the order they were made; other clips in name order
  (name them `1.mp4`, `2.mp4`, `3.mp4`).
- Download clips at 720p or higher, vertical (9:16).
