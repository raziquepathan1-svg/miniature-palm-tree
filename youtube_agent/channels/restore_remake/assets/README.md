# Optional extras for Restore Remake Studio videos

Put these files here and the agent adds them automatically. Every one is optional.

- `music.mp3`: quiet background music. Use only royalty-free music you're allowed to use on YouTube, for
  example from the **YouTube Audio Library** (YouTube Studio → Audio Library, "no attribution required").
- `intro.mp4` / `outro.mp4`: short landscape (16:9) clips played before/after each video.
- `intro_vertical.mp4` / `outro_vertical.mp4`: the same for vertical Shorts (9:16).
